# Support

## Getting help

| Channel | Use for |
|---------|---------|
| [GitHub Issues](https://github.com/RohitThakur/sandesh-email-service/issues) | Bugs, feature requests, questions |
| [Discussions](https://github.com/RohitThakur/sandesh-email-service/discussions) | Ideas, Q&A, show-and-tell (enable in repo settings) |
| Email (security only) | See [SECURITY.md](./SECURITY.md) |

## Before opening an issue

1. Search [existing issues](https://github.com/RohitThakur/sandesh-email-service/issues).
2. Confirm you are on a recent commit or release tag.
3. Include reproduction steps, versions, and logs.
4. For SDK/API problems, share the minimal request body (redact secrets).
