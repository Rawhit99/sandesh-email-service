# Brand assets

| File | Usage |
|------|--------|
| `sandesh-icon.png` | App UI + favicon source (transparent, cropped) |
| `sandesh-logo.png` | Same as `sandesh-icon.png` |
| `sandesh-logo-readme.png` | GitHub README (white background, large display) |

Falcon-in-flight on an S-curve — swift messenger. Teal gradient, coral accents.  
*Sandesh* (संदेश) = message.

**GitHub README:** commit `sandesh-logo-readme.png` with the repo — untracked files will not render on github.com.

After updating icons, run `python scripts/sync-brand-assets.py` to refresh crops and README PNG.
